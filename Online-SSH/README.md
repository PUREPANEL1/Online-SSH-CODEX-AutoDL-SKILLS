# Online SSH

一个用于 Codex 的 SSH 连接 skill：自动生成或复用本地密钥，先显示公钥，引导用户配置免密登录，再验证连接并打开右侧终端。

免密配置生效后，后续只需正常开机，提供 **服务器名称，登录指令**，无需提供服务器密码。每次使用本次开机后的最新登录指令，端口不从历史记录中复用。

## 仓库内容

```text
online-ssh/

│   └── openai.yaml

```

这是指令型 skill，需要运行环境提供本地命令执行工具。右侧终端功能需要 Codex 桌面应用的终端打开工具；其他环境可以使用普通本地终端。

## 安装与调用

将本目录放入你的 Codex skills 目录，文件夹名称使用 `online-ssh`。默认目录为 `~/.codex/skills/online-ssh`；如果设置了 `CODEX_HOME`，使用对应目录下的 `skills/online-ssh`。

Windows 默认位置：

```text
%USERPROFILE%\.codex\skills\online-ssh
```

在 Codex 中调用：

```text
$online-ssh
```

本地需要可用的 `ssh` 和 `ssh-keygen`。请确保生成密钥时的账户权限允许你自己的终端读取私钥。

## 首次配置免密登录

1. 调用 skill，由它生成或复用专用 SSH 密钥对，并显示实际公钥。
2. 将完整公钥添加到云平台的 SSH 公钥设置，或目标登录用户的 `~/.ssh/authorized_keys`。
3. 按云平台要求让配置生效，再复制实例的最新 SSH 登录指令。
4. 输入服务器名称和登录指令，全部录入后回复“输入完成”。
5. Skill 按顺序编号，使用对应私钥执行仅公钥认证的验证，再打开右侧终端并给出连接命令。

私钥留在本地，公钥配置到服务器。不要把私钥粘贴到云平台公钥表单。

### AutoDL

1. 进入 **控制台 → 容器实例**。
2. 点击 **设置SSH免密登录** 或当前页面上的对应密钥设置入口。
3. 粘贴 skill 显示的完整单行公钥并保存。
4. 对已运行的实例，先保存并结束需要保留的任务，再关机、开机；新建实例按平台流程启动。平台公钥配置在实例重启后或新建实例时生效。[官方说明](https://www.autodl.com/docs/ssh/)
5. 等目标实例显示“运行中”，复制该实例当前的 SSH 登录指令，端口以这次开机后显示的值为准。

**配置生效后的日常使用：正常开机 → 复制最新登录指令 → 提供“服务器名称，登录指令”。无需提供密码，也无需每次重复配置同一把公钥。**

更换本地密钥、新增未配置的服务器或重置服务器后，可能需要重新配置公钥。更换电脑时也需要可用的对应私钥，或为新电脑重新配置公钥。

### 普通 Linux 服务器

将公钥添加到目标登录用户的 `~/.ssh/authorized_keys`。以 `root` 登录时，文件为 `/root/.ssh/authorized_keys`。Skill 会提供适合实际公钥的安装指令，保留原有公钥，并检查目录、文件的权限与所有者。

如果当前无法登录，可通过云平台控制台或已有的服务器终端完成首次配置。使用这种方式安装公钥通常无需重启实例。

## 输入格式与编号

每台服务器单独一行，只需两个字段：

```text
实验服务器，ssh -p 2222 user@server.example.com
验证服务器，ssh -p 2223 user@other.example.com
```

以上为虚构示例，请使用你自己的服务器名称与最新登录指令。支持中文逗号或英文逗号。

输入完成后回复：

```text
输入完成
```

服务器按输入顺序从 1 编号，单台服务器也有编号。后续可通过编号选择目标，同一轮追加的服务器使用下一个编号。

Skill 可以复用已有密钥，但每次调用都会收集最新的服务器记录，避免连接到旧端口。不会要求输入服务器密码。

## 右侧终端

验证免密登录后，skill 自动请求打开右侧终端。终端输入接口可用时，会执行连接命令；接口仅支持打开或读取时，会明确说明限制，并提供一条完整命令让用户粘贴执行。

打开本地终端不等于已经连接服务器；工具执行环境的 SSH 会话也不等于右侧可见终端的会话。

连接后的标题格式为：

```text
1 - 实验服务器
```

支持标题控制序列的终端可以使用远程 shell 命令设置标题。部分界面会覆盖或忽略该标题，需要使用界面的标签重命名功能。Skill 不会声称一个未生效的标题修改已完成。

## 常见问题

| 现象 | 检查方向 |
| --- | --- |
| 仍要求服务器密码 | 公钥认证没有成功；确认目标用户的公钥配置与最新端口。 |
| `Load key ... Permission denied` | 本地私钥读取权限或所有者有误，尤其是沙箱账户生成、桌面用户使用的情况。 |
| `Permission denied (publickey,password)` | 确认匹配的公钥已安装在正确的用户下，检查权限和实例配置生效状态。 |
| 更换端口后连接失败 | 提供本次开机后的最新 SSH 指令，不沿用旧端口。 |
| 首次连接出现信任询问 | 核对可信来源的主机指纹；确认后输入完整的 `yes`，不是 `y`。 |

免服务器密码与私钥口令是两回事：如果私钥本身有口令，仍可能需要解锁私钥或使用 `ssh-agent`。

## GitHub 发布与脱敏

此目录仅包含通用 skill 指令、界面配置、README 和忽略规则。示例域名、用户名、端口与名称都是占位示例，未附带真实服务器记录、公私钥、密码、账户信息、个人绝对路径、截图或会话日志。

上传本目录即可，不要上传包含运行文件的整个聊天工作目录。生成的私钥和公钥不属于仓库内容，`.gitignore` 已排除常见密钥文件及运行目录。

`.gitignore` 不会删除已经提交的敏感内容。如果后续自行加入连接记录或密钥，应在发布前重新检查；私钥或密码一旦公开，应更换对应凭据。
